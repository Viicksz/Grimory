# Starsweeper

Descrição:
A Starsweeper é para pilotos que entendem que o céu não desaparece quando o sol vai embora. A linha sempre teve uma obsessão elegante por orientação, estabilidade e voo limpo em baixa visibilidade. Não são vassouras feitas para entrar rugindo no campo como se tivessem uma plateia particular. São feitas para atravessar noite, neblina e distância sem transformar cada curva em uma discussão com o destino.

Perfil geral:
Navegação estável em baixa visibilidade e viagens noturnas.
