# Onda Aérea

Descrição:
A Air Wave é uma linha para pilotos que acreditam, às vezes corretamente, que força demais estraga uma boa curva. Essas vassouras não entram no ar brigando com ele; elas negociam. São suaves, responsivas e irritantemente elegantes nas mãos de quem sabe manter movimento contínuo. Não servem para quem quer atravessar o campo como um tijolo encantado. Servem para quem prefere fazer o adversário errar tentando acompanhar o ritmo.

Perfil geral:
Trajetórias fluidas e manobras coletivas para Artilheiros.
