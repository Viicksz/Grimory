# Artesanal

Descrição:
Todo ano aparece alguém perguntando qual é a melhor vassoura da categoria Artesanal. A pergunta já mostra que a pessoa não entendeu a categoria. Artesanal não é uma fabricante, é um conjunto de vassouras feitas por gente que sabe trabalhar madeira melhor do que a maioria dos engenheiros mágicos sabe desenhar projetos. Cada uma foi feita para uma finalidade específica. Compará-las é como perguntar se um martelo é melhor que uma chave de fenda.

Perfil geral:
Modelos acessíveis e versáteis, com desempenho variável conforme a fabricação.
