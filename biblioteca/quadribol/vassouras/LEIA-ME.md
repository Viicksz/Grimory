# Catálogo de Vassouras

Cada modelo real possui seu próprio arquivo Markdown nesta pasta e pertence a uma linha exibida no `/jogador`.

Use `biblioteca/modelos/Vassoura.md` como estrutura. O comando `/jogador` só oferece arquivos que possuam `Bonus de Voo` inteiro e `Vida maxima` positiva; este arquivo de orientação não aparece como opção.

Os bônus automáticos registram somente modificadores gerais de Vôo, Reflexo e Fortitude. Bônus condicionais, dados adicionais, Disparadas e demais particularidades permanecem preservados em `Especificacoes` para serem aplicados apenas na situação descrita.
