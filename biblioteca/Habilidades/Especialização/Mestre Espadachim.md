# Mestre Espadachim

Categoria:
Especialização

Custo de aquisição:
20 XP

Custo de PH:
Passivo ou 2ph

Descrição:
● **Passivo:** Aumenta o nível de periculosidade base do ataque inimigo para 5 + Reflexo, permitindo a realização de um contra-ataque.
● **2ph:** Permite antecipar golpes inimigos durante uma luta com espadas, concedendo +2 de bônus para defender-se ou esquivar-se dos golpes.

Requisitos de Aquisição:
• 20 XP
• Esgrima como perícia treinada.
