# Musicallium

Categoria:
Encantamentos

Ano de desbloqueio:
2º Ano

Grau de dificuldade:
Básico Ⅱ

Descrição:
Encanta um objeto para reproduzir músicas, sons ou efeitos sonoros escolhidos pelo conjurador. O encantamento pode ser configurado para tocar continuamente, repetir uma sequência específica ou ser ativado mediante determinadas condições definidas durante a conjuração.
