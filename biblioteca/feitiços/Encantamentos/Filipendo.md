# Filipendo

Categoria:
Encantamentos

Ano de desbloqueio:
2º Ano

Grau de dificuldade:
Básico Ⅱ

Descrição:
Projeta uma poderosa onda de impacto que arremessa o alvo para longe. Após o impacto inicial, o alvo — seja um objeto ou uma criatura — entra em um movimento aéreo giratório antes de cair ao chão, podendo ser utilizado para criar aberturas, interromper ações ou realizar combinações ofensivas.
**Pode ser conjurado como uma ação bônus para conceder vantagem em uma ação ofensiva realizada como ação padrão no mesmo turno**
**A cada Filipendo recebido, o alvo deve realizar um Teste de Fortitude com CD 8, aumentando em +2 para cada Filipendo consecutivo, em caso de falha o alvo recebe um debuff de -2 em todas as ações durante 1d4 turnos. Se a falha for crit. o alvo perderá a consciência**
