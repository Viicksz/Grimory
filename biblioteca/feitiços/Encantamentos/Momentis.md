# Momentis

Ano de desbloqueio:

Descrição:
Um feitiço que aprisiona um instante em sucessivos lampejos de luz mágica. Ao término da conjuração, a memória visual deve ser transferida para uma superfície através do toque, revelando-se como uma fotografia permanente. Sem uma superfície para recebê-la, a captura se desfaz.
