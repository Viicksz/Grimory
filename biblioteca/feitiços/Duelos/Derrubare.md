# Derrubare

Categoria:
Duelos

Ano de desbloqueio:
2º Ano

Grau de dificuldade:
Básico Ⅱ

Descrição:
Cria uma pressão repentina contra a caixa torácica do alvo, como um empurrão concentrado que o lança para trás e quebra seu equilíbrio. É usado para abrir distância, interromper avanços ou derrubar o oponente durante uma troca de feitiços.
**1d6+3 de dano concussivo.**
**O alvo deve realizar um teste de Fortitude para tentar se levantar novamente.**
**Quando conjurado como reação, geralmente para impedir um avanço do inimigo, a CD para sua execução aumenta em +4.**
