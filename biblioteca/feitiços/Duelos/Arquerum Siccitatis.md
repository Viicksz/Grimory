# Arquerum Siccitatis

Categoria:
Duelos

Ano de desbloqueio:
7º Ano

Grau de dificuldade:
Avançado Ⅶ

Descrição:
O bruxo controla uma enorme porção de terra correspondente ao local onde o lampejo atingiu. Pode fazer o local assumir uma forma desejada ou lançar uma formação grotesca de rochas contra o oponente. Este feitiço requer demasiada maestria e concentração absoluta no duelo para ser executado.
**No turno de conjuração, cria rachaduras no solo.**
**No segundo turno, permite controlar ou moldar a porção de terra.**
**No terceiro turno, aplica 6d8+8 de dano concussivo.**
