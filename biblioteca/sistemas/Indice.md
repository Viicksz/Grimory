# Sistemas

Esta pasta reúne as regras destinadas a consultas gerais. Cada sistema mantém sua biblioteca detalhada em sua própria pasta; os arquivos daqui funcionam como índice e visão de conjunto para um futuro comando de consulta.

## Sistemas disponíveis

### Quadribol

Consulta: `Quadribol.md`

Fontes detalhadas:

» `biblioteca/quadribol/Manobras.md`

» `biblioteca/quadribol/Condicoes.md`

» `biblioteca/quadribol/Faltas.md`

» `biblioteca/quadribol/vassouras/`

### Feitiços

Consulta: `Feitiços.md`

O guia reúne as regras gerais de execução e encaminha para as fichas completas da pasta `biblioteca/feitiços/`, que continuam sendo a autoridade para cada magia individual.

## Como o comando deve consultar

» Mostrar primeiro os sistemas disponíveis.

» Depois permitir a escolha de uma seção, mantendo a descrição original completa.

» Usar os títulos e os nomes exatamente como aparecem na biblioteca.

» Quando uma regra depender de uma ficha, manobra, condição ou vassoura, encaminhar para a entrada correspondente em vez de criar uma versão resumida ou divergente.
